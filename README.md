## 📋 Tentang Proyek

**AI Pet Video Prompt Generator** adalah aplikasi web yang membantu kreator konten menghasilkan prompt video AI berkualitas tinggi untuk hewan peliharaan. Didesain khusus untuk platform seperti **Veo, Kling, Hailuo, Wan, dan PixVerse**.

Dengan antarmuka yang intuitif, Anda bisa memilih jenis hewan, genre video, lokasi, dan pencahayaan, lalu mendapatkan **3 prompt siap pakai** (Image Prompt + 2 Motion Prompts) dalam hitungan detik.

### ✨ Fitur Unggulan

- 🔐 **Sistem Login** – Akses aman dengan session localStorage
- 🐱 **10 Pilihan Hewan** – Kucing, Anjing, Kelinci, Hamster, Bebek, Burung, Landak, Ferret, dll.
- 🎭 **6 Genre Video** – Cute, Funny, Emotional, Heartwarming, Friendship, Surprise
- 🏠 **6 Lokasi Rumah** – Ruang Tamu, Dapur, Kamar Tidur, Balkon, dll.
- ☀️ **5 Opsi Pencahayaan** – Pagi, Siang, Senja, Mendung, Lampu Hangat
- 💡 **Generate 10 Ide Viral** – Otomatis atau dari ide Anda sendiri
- 📸 **3 Prompt Format** – Image Prompt + Motion Prompt 1 + Motion Prompt 2
- 📋 **Copy & Download** – Salin semua prompt atau download sebagai file `.txt`
- 🛡️ **Anti-Copy Protection** – Proteksi dasar untuk konten
